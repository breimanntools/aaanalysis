### The effort scale (calibrated on this repo, not generic)

Effort here is dominated by the **fixed overhead every new public symbol pays**, not by the
algorithm. A new symbol must clear ~15 gates in `tests/unit/api_tests/` (abbreviation registry,
docstring contracts, plot-return contract, param coverage, backend-import hygiene), get a
docstring in house style, an example notebook demonstrating **every** public parameter (a
permanent zero-gap CI gate), and ~30 tests per method. Sizing therefore keys off *what kind of
surface* the change adds:

| **XL** | > 1 week, or blocked until a decision record exists | #276, #483, the omics track |

## Reject / Defer appendix (with cited rule)

- **#497 ❌→ProtXplain** — the border decision record lists *feedback data — which workflows
  actually solve users' problems* as the downstream moat, and its no-consumer rationale applies
  verbatim: don't create permanent semver surface with no in-package caller.
- **#492 ⏸️** — rejected-optimization list: *sparse one-hot encoding — a return-dtype/structure
  change, an API change, not a numerical-equivalence question; risky for a public encoder.*
  Compounded by there being no sparse input path at all.
- **#65 ⏸️** — scope test: *balloons the dependency surface* (three search tools + three aligners
  + a cloud API), far past the single-binary precedent set for the motif scanner.
- **#42 ⏸️** — scope test: *a research program rather than a package feature*, plus a
  CONFIRM-FIRST `_data/` rewrite of published scales.
- **#50 · #51 · #54 · #265 ⏸️** — dependency surface (imodels/alibi · captum + a DL runtime ·
  DoWhy/EconML/causal-learn/gCastle · gplearn/pysr). The border ADR routes causal and neural
  attribution downstream; `torch` is deliberately isolated in `[embed]` to keep the DL stack out
  of `[pro]`.
- **#263 ⏸️** — no GPU runner exists in CI, so the issue's own KPI is unverifiable; output-affecting
  work additionally needs a declared tolerance tier and a frozen anchor.
- **#496 · #499 ⏸️** — v2 architecture; the typed-result child is gated by *don't introduce typed
  row records until the v2 migration*, and typed I/O contracts belong downstream.
- **#498 ⏸️** — hard-blocked by unbuilt #483; no rule conflict.
- **#491 ⏸️** — fails the scope test twice: balloons the dep surface (anndata/scverse) and is not
  sequence-based protein prediction; pseudobulk is already Scanpy/decoupler's job.
- **#64 🔄 (blocked)** — contradicts the standing decision to neither test nor integrate the
  orphaned conservation module; needs that decision explicitly superseded first.
